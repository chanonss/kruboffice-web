macOS

macOS 11 ขึ้นไป · ชิป Apple และ Intel

รุ่น macOS เร็ว ๆ นี้ครับ ระหว่างนี้ใช้บนเว็บได้ที่ kruboffice.app
เครื่องนี้

Windows

Windows 10 และ 11 แบบ 64 บิต

ดาวน์โหลดสำหรับ Windows KrubOffice-0.1.0-windows-x64.msi · 81 MB

ติดตั้งบน macOS

  1. กด ดาวน์โหลดสำหรับ macOS แล้วดับเบิลคลิกไฟล์ .dmg ที่ชื่อขึ้นต้นด้วย KrubOffice (อยู่ในโฟลเดอร์ Downloads)
  2. ในหน้าต่างที่เปิดขึ้น ลากไอคอน KrubOffice ไปวางบนโฟลเดอร์ Applications แล้วรอให้คัดลอกเสร็จ
  3. เปิดโฟลเดอร์ Applications แล้วดับเบิลคลิก KrubOffice ครั้งแรก macOS จะแจ้งว่าเปิดไม่ได้ เพราะตรวจสอบผู้พัฒนาไม่ได้ ให้กด Done (เสร็จสิ้น) อย่ากด Move to Trash
  4. เปิด System Settings (การตั้งค่าระบบ) › Privacy & Security (ความเป็นส่วนตัวและความปลอดภัย) แล้วเลื่อนลงไปที่หัวข้อ Security จะเห็นข้อความเรื่อง KrubOffice ให้กด Open Anyway (เปิดอยู่ดี) แล้วใส่รหัสผ่านของเครื่อง
  5. macOS ถามยืนยันอีกครั้ง กด Open Anyway KrubOffice จะเปิดขึ้น ครั้งต่อไปดับเบิลคลิกเปิดได้ตามปกติ
macOS 14 หรือเก่ากว่าคลิกขวา (หรือกด Control ค้างแล้วคลิก) ที่ KrubOffice ในโฟลเดอร์ Applications เลือก Open แล้วกด Open อีกครั้ง ทำครั้งเดียวพอ
ทำไมต้องทำขั้นตอนนี้KrubOffice ใช้ฟรีและยังไม่ได้ลงทะเบียนกับโปรแกรมนักพัฒนาแบบเสียค่าใช้จ่ายของ Apple macOS จึงถามก่อนเปิดครั้งแรก ไฟล์ดาวน์โหลดมาจากหน้า Releases ของโครงการบน GitHub โดยตรง และตรวจสอบได้ด้วยไฟล์ SHA256SUMS

ให้ไฟล์เปิดด้วย KrubOffice

คลิกขวาที่ไฟล์ เช่น .docx แล้วเลือก Get Info (ข้อมูล) ในส่วน Open with (เปิดด้วย) เลือก KrubOffice แล้วกด Change All… (เปลี่ยนทั้งหมด) ทำแบบเดียวกันกับ .xlsx และ .pptx

ถอนการติดตั้ง

ลาก KrubOffice จากโฟลเดอร์ Applications ไปที่ถังขยะ

รู้เมื่อมีรุ่นใหม่

กดติดตามเพจ Facebook ของ KrubOffice เพื่อรับข่าวเมื่อมีรุ่นใหม่ แล้วดาวน์โหลดจากหน้านี้มาติดตั้งทับได้เลย งานที่บันทึกไว้ไม่หาย

ติดตั้งบน Windows

  1. กด ดาวน์โหลดสำหรับ Windows แล้วดับเบิลคลิกไฟล์ .msi ที่ชื่อขึ้นต้นด้วย KrubOffice (อยู่ในโฟลเดอร์ Downloads)
  2. ถ้าขึ้นหน้าต่างสีน้ำเงิน Windows protected your PC (Windows ปกป้องพีซีของคุณ) ให้กด More info (ข้อมูลเพิ่มเติม) แล้วกด Run anyway (เรียกใช้ต่อไป)
  3. เมื่อ Windows ถามว่าอนุญาตให้แอปเปลี่ยนแปลงอุปกรณ์หรือไม่ กด Yes แล้วทำตามขั้นตอนติดตั้ง ยอมรับสัญญาอนุญาต และกด Install
  4. เมื่อเสร็จ เปิด KrubOffice ได้จากเมนู Start
ทำไมถึงมีคำเตือนKrubOffice ใช้ฟรีและยังไม่มีใบรับรองการลงนามแบบเสียค่าใช้จ่าย Windows จึงเตือนก่อนติดตั้ง ไฟล์ดาวน์โหลดมาจากหน้า Releases ของโครงการบน GitHub โดยตรง และตรวจสอบได้ด้วยไฟล์ SHA256SUMS

ให้ไฟล์เปิดด้วย KrubOffice

เปิด Settings (การตั้งค่า) › Apps (แอป) › Default apps (แอปเริ่มต้น) เลือก KrubOffice แล้วตั้งให้เปิดไฟล์ .docx .xlsx และ .pptx หรือคลิกขวาที่ไฟล์ › Open with › Choose another app › KrubOffice › Always

ถอนการติดตั้ง

เปิด Settings › Apps › Installed apps หา KrubOffice แล้วกด Uninstall
